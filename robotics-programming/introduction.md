### \#Robotics programming

## Introduction

Robotics programming is the process of writing instructions to control
robots and their movements.

\##Applications

* Robot control
* Automation
* Sensor programming
* Robot movement

\##Objective
To understand the basics of programming
and its application in robotics.



#### **What is Git?**



**G**it is a version control system used to track changes in files and manage project development.



##### **Basic Git Concepts**



* **Repository:** A place where projects files are stored.
* **Commit:** A saved snapshot of changes.
* **Branch:** A separate line of development.
* **Clone:** Creating a local copy of a repository.
* **Push:** Uploading local changes to GitHub.
* **Pull:** Downloading remote changes.
